# Images

This project references images by filename in `src/data/heritageSites.ts`
(e.g. `/images/hundred-islands-hero.jpg`). No binary image files are
included in this submission-ready ZIP, so before running the site:

1. Add your own photos of Hundred Islands, Cape Bolinao Lighthouse, and
   Balungao Hot Spring to this folder using the exact filenames referenced
   in `src/data/heritageSites.ts`, **or**
2. Edit `src/data/heritageSites.ts` and point `heroImage.src` / `gallery[].src`
   at whichever filenames you actually add.

Recommended sizes: hero images ~1600×900px, gallery images ~800×600px,
saved as `.jpg` or `.webp` and compressed (e.g. with Squoosh) before adding
them here, to keep the "Lightning-Fast" performance requirement intact.
